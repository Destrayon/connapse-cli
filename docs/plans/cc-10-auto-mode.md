# CC-10 — Agents can use the CLI in auto mode without being blocked

1. **Research.** Goal: name why the CON-288 CLI calls were denied (exact denials) and compare with gh and other agent-friendly CLIs. Done when `docs/research/auto-mode-denials-2026-11-09.md` is written.
2. **Agent task script and baseline.** Goal: a script that runs everyday agent tasks (sign-in check, upload, search, list, update, delete) in a headless Claude Code auto mode session and counts denials, written before any CLI change. Done when the baseline run against the unchanged CLI is recorded.
3. **Deletes go through the owner's approval.** Goal: `files delete`, `container delete` and `memory forget` are sent through the server's approval gate, so a token that asks for approval gets a held request; `connapse approval status` reports the decision. Done when unit tests cover it and a held delete is seen on a real server.
4. **Auto mode setup for agents.** Goal: `connapse setup claude-code` prints the user-level auto mode entries that describe the signed-in Connapse server, and the README explains agent use. Done when the command and docs exist with tests.
5. **Prove it and ship.** Goal: the task script runs with zero denials, the repo's tests pass, and a PR into main is open. Done when the PR is open and ClaudePM is told.
